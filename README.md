# Lively Presets Manager

A powerful, independent preset manager for [Lively Wallpaper](https://github.com/rocksdanister/lively).

This tool allows you to:
- **Save Presets**: Capture the current configuration of any active Lively Wallpaper.
- **Save Per Monitor**: Manage presets specifically for different monitors.
- **Restore Instantly**: Apply saved presets with a single click.
- **Manage**: Delete old presets and keep your library organized.

## Features
- 🚀 **One-Click Startup**: Launches server, client, and browser instantly.
- 🖥️ **Multi-Monitor Support**: Works seamlessly with multi-monitor setups.
- 🎨 **Modern UI**: Clean, dark-mode interface.
- 🛠️ **Local Control**: Runs entirely on your machine, interacting directly with Lively's configuration files.

## Prerequisites
- **Node.js**: You must have Node.js installed to run this application. [Download Here](https://nodejs.org/).
- **Lively Wallpaper**: Must be installed and running.

## Installation & Usage

1.  **Download** this repository.
2.  **Double-click** the `start_app.bat` file in the root directory.
    -   *First time run*: It will automatically install all necessary dependencies. This might take a minute.
    -   *Subsequent runs*: It will launch instantly.
3.   The application will open in your default web browser at `http://localhost:3001`.
